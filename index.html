Deeplearning3 Control Center

Configure training, register datasets, monitor jobs, generate commands, and run/use-case workflows for MMWM, OmniLatent, HPWM, LGQ, and the Gaussian Encoder.

Static dashboard Optional local API Dataset uploader Command generator Training status
Backend: not connected

This page works standalone. If you later run a local backend, set its API URL and this page can poll status or send JSON job requests.

1. Prepare

Install dependencies, pick a model family, define data shape, then validate with tests.


        
2. Train
Use generated commands or export JSON config. MMWM supports deterministic smoke data and custom transition batches.
No active job.

        
3. Use
Run reconstruction, multimodal translation, latent rollout, benchmarking, evaluation, tokenization, or tool routing from the use-case panel.
